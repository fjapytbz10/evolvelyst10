# ecocatalyst — Astro responsive one-page

Minimal pre-launch page for ecocatalyst.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Layout

The complete hero is horizontally and vertically centered using CSS Grid.
The design is responsive for desktop, tablet, mobile, and short-height screens.
